## Never

- bypass any checks or tests without double checking with the user or provide any good justification
- merge into main without checking with the project owner
- commit directly to main unless getting authorization from project owner

## Always

- check latest documentation when using open source libraries when developing. Be aware of what versions of the libraries are used.
- provide detailed comment and documentation of the design when writing code.
- include writing relevant tests when generating code.
- document changes in CHANGELOG.md
- update CONTRIBUTING.md, README.md and PLAN.md if necessary.
- commit using the user's git credential.
- run test and checks when the task finished and commit with proper commit messages.
- work on a new branch, only merge into main after reviewed by human author.
- provide reasoning and inform the user your plan while you work
